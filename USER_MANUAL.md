## Getting Started

### First Time Setup

1. **Access the System**
   - Open your web browser
   - Navigate to: `http://127.0.0.1:8000`
   - You'll see the login page

2. **Admin First Login**
   - Use credentials created during setup
   - Email: `your-admin@email.com`
   - Password: `your-password`

3. **Alumni Registration**
   - Click "Register here" on login page
   - Fill registration form
   - Wait for admin approval
   - Check email for approval notification

## Admin Guide

### Dashboard Overview

After logging in as admin, you'll see:
- **Total Alumni** — Count of approved alumni
- **Pending Approvals** — Alumni waiting for approval
- **Total Events** — Number of events created
- **Total Jobs** — Number of job postings
- **Total Donations** — Sum of all donations

### Managing Alumni Registrations

**Approve/Reject Alumni:**
1. Click "Approvals" in sidebar
2. View list of pending registrations
3. Review alumni details
4. Click "Approve" to activate account
5. Click "Reject" to delete registration
6. Alumni receives email notification on approval

**View Alumni Directory:**
1. Click "Alumni Directory" in sidebar
2. Use search bar to find alumni
3. Apply filters (batch year, department, city)
4. Click "View Profile" to see full details
5. Click "Clear Filters" to reset

### Managing Events

**Create Event:**
1. Click "Events" in sidebar
2. Click "Create Event" button
3. Fill event details:
   - Title (required)
   - Description (required)
   - Event type (seminar, workshop, etc.)
   - Venue
   - Date & time (required)
   - Registration deadline
   - Banner image (optional)
   - Active status checkbox
4. Click "Create Event"
5. All approved alumni receive email notification

**Edit Event:**
1. Go to Events list
2. Click "Edit" button on event card
3. Update details
4. Click "Edit Event" to save

**Delete Event:**
1. Go to Events list
2. Click "Delete" button
3. Confirm deletion
4. Event and all registrations are removed

**View Registrations:**
1. Click on event to view details
2. See registration count
3. View list of registered alumni

### Managing Jobs

**Post Job:**
1. Click "Jobs" in sidebar
2. Click "Post Job" button
3. Fill job details:
   - Title (required)
   - Company (required)
   - Location
   - Job type (full-time, part-time, etc.)
   - Description (required)
   - Requirements
   - Salary range
   - Apply link
   - Last date
   - Active status checkbox
4. Click "Post Job"
5. All approved alumni receive email notification

**Edit Job:**
1. Go to Jobs list
2. Click "Edit" button
3. Update details
4. Click "Edit Job" to save

**Delete Job:**
1. Go to Jobs list
2. Click "Delete" button
3. Confirm deletion
4. Job and all referrals are removed

**View Referrals:**
1. Go to Jobs list
2. Click "Referrals" button on job
3. See list of all referrals
4. View referee details and notes

### Managing Sponsorships

**Add Sponsorship:**
1. Click "Sponsorships" in sidebar
2. Click "Add Sponsorship" button
3. Fill sponsor details:
   - Sponsor name (required)
   - Email (required)
   - Phone
   - Company
   - Sponsorship type (Platinum/Gold/Silver/Bronze)
   - Amount (required)
   - Purpose
   - Description
   - Logo (optional)
   - Website URL
   - Active status checkbox
4. Click "Add Sponsorship"

**Edit/Delete Sponsorship:**
1. Go to Sponsorships list
2. Click "Edit" or "Delete" button
3. Make changes or confirm deletion

### Viewing Reports

**Reports Dashboard:**
1. Click "Reports" in sidebar
2. View overview statistics
3. See charts and graphs:
   - Alumni by batch year
   - Alumni by department
   - Alumni by city
   - Events by type
   - Jobs by type
   - Donation summary

**Alumni Report:**
1. Click "Alumni Report" card
2. Apply filters (batch, department, city)
3. Click filter button
4. View filtered results
5. Click "Export CSV" to download data

**Donation Report:**
1. Click "Donation Report" card
2. View total amount, count, average
3. See donations by type
4. View recent donations list

**Event Report:**
1. Click "Event Report" card
2. View all events with registration counts
3. See event types and statuses

**Job Report:**
1. Click "Job Report" card
2. View all jobs with referral counts
3. See job types and statuses

### Viewing Donations

1. Click "Donations" in sidebar
2. View all donations (including anonymous)
3. See total amount and donor count
4. View donation details (amount, type, purpose, date)

## Alumni Guide

### First Time Login

1. **Register Account:**
   - Click "Register here" on login page
   - Fill all required fields
   - Submit form
   - Wait for admin approval email

2. **After Approval:**
   - Check email for approval notification
   - Log in with your credentials
   - You'll see the alumni dashboard

### Dashboard

Your dashboard shows:
- Your profile summary
- Quick stats
- Links to features

### Managing Your Profile

**Update Profile:**
1. Click "My Profile" in sidebar
2. Fill/update sections:
   - **Academic Info:** Batch year, department, degree
   - **Professional Info:** Company, designation, industry, skills, LinkedIn
   - **Personal Info:** City, state, country, bio
   - **Profile Picture:** Upload your photo
3. Click "Save Changes"
4. Profile is immediately updated

**View Other Profiles:**
- Profiles are visible to all logged-in users
- Click "View Profile" on any alumni card
- See their academic, professional details
- View skills and LinkedIn profile

### Registering for Events

**Browse Events:**
1. Click "Events" in sidebar
2. View all active events
3. See event details (date, venue, type)

**Register for Event:**
1. Click on event card to view details
2. Read full description
3. Click "Register Now" button
4. Confirmation message appears
5. You're registered!

**View Your Registrations:**
- Registered events show "You're Registered" badge
- You can see registration count

### Browsing Jobs

**View Jobs:**
1. Click "Jobs" in sidebar
2. Browse all active job postings
3. See job details (company, type, location, salary)

**View Job Details:**
1. Click on job card
2. Read full description and requirements
3. See apply link (if provided)
4. Click "Apply Now" to go to external site

### Referring Candidates

**Submit Referral:**
1. Go to job details page
2. Scroll to "Refer Someone" section
3. Fill referral form:
   - Referee name (required)
   - Referee email (required)
   - Note (optional)
4. Click "Submit Referral"
5. Confirmation message appears

**View Your Referrals:**
- Your referrals appear below the form
- See referee name, email, date
- View your notes

### Making Donations

**Donate:**
1. Click "Donations" in sidebar
2. Click "Make a Donation" button
3. Fill donation form:
   - Amount (required)
   - Donation type (one-time, monthly, yearly)
   - Purpose (optional)
   - Message (optional)
   - Payment method
   - Anonymous checkbox (hide your name)
4. Click "Donate Now"
5. Receive email confirmation

**View Your Donations:**
1. Go to Donations page
2. See your donation history
3. View total amount donated
4. See transaction details

### Viewing Sponsorships

1. Click "Sponsorships" in sidebar (if visible)
2. View all active sponsors
3. See sponsor logos and details
4. Click "Website" to visit sponsor site

## Troubleshooting

### Login Issues

**Problem:** Can't log in  
**Solution:**
- Check email and password are correct
- Ensure caps lock is off
- If alumni, check if account is approved
- Contact admin if issue persists

**Problem:** "Account pending approval" message  
**Solution:**
- Your account needs admin approval
- Wait for approval email
- Contact admin if waiting too long

### Profile Issues

**Problem:** Can't upload profile picture  
**Solution:**
- Check file size (max 5MB recommended)
- Use JPG, PNG, or GIF format
- Try a different image
- Clear browser cache

**Problem:** Profile changes not saving  
**Solution:**
- Check all required fields are filled
- Look for error messages
- Try refreshing the page
- Contact admin if issue persists

### Event Registration Issues

**Problem:** Can't register for event  
**Solution:**
- Check if registration is still open
- Check registration deadline
- Ensure event is active
- You may already be registered

**Problem:** Don't see events  
**Solution:**
- Only active events are shown to alumni
- Check if any events exist
- Contact admin

### Job Referral Issues

**Problem:** Can't submit referral  
**Solution:**
- Check all required fields are filled
- Ensure valid email format
- Check if job is still active
- Try refreshing the page

### Donation Issues

**Problem:** Donation not showing  
**Solution:**
- Check if payment was completed
- Refresh the page
- Check email for confirmation
- Contact admin if issue persists

### General Issues

**Problem:** Page not loading  
**Solution:**
- Check internet connection
- Refresh the page (F5)
- Clear browser cache
- Try different browser
- Contact admin

**Problem:** Email notifications not received  
**Solution:**
- Check spam/junk folder
- Verify email address in profile
- Contact admin to check email settings
